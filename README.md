# Map Zoom Out

<img src="mod_icon.jpg">

A small mod for **American Truck Simulator** that lets you zoom out further on the world map.

- Version: 1.1
- Game version: 1.61.x
- Category: UI

## Installation

1. Copy `map_zoom_out.scs` into your ATS `mod` folder:
   - Windows: `Documents\American Truck Simulator\mod`
   - macOS: `~/Library/Application Support/American Truck Simulator/mod`
   - Linux: `~/.local/share/American Truck Simulator/mod`
2. Start the game and open the **Mod Manager**.
3. Enable **Map Zoom Out 1.1** and move it to the **top** of the active mods list.

## Compatibility

Tested and working on American Truck Simulator 1.61.x.
